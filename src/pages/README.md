# LKNC Web POS (Firebase + Vue)

A free web-based Billing & POS system for Net Centres, Xerox, Print & Browsing shops.

### 🚀 Features
✔ Billing + PDF Invoice  
✔ Dashboard with Sales & Top Service  
✔ Customer Management  
✔ Services Management  
✔ Ledger (Udhaar)  
✔ Expenses Management  
✔ Reports  
✔ Logo Upload  
✔ Firebase Auth, Firestore, Storage  
✔ Free Hosting (Firebase)

---

### 🛠 Tech Stack

| Feature | Tech |
|--------|-----|
| Frontend | Vue 3 + Vite |
| Styling | Tailwind CSS |
| Database | Firestore |
| Auth | Firebase Auth |
| Uploads | Firebase Storage |
| Reports | Chart.js |
| PDF | jsPDF |
| Hosting | Firebase Hosting |

---

### 📌 Project Setup

npm install
